Rota do Ouro Verde - versão profissional

Arquivos incluídos:
- index.html
- style.css
- script.js

ANTES DE PUBLICAR:
1) Mantenha sua pasta /assets exatamente como já está no projeto atual.
2) Se quiser ativar o formulário no Cloudflare Free:
   - crie uma conta no Formspree
   - pegue o endpoint no formato https://formspree.io/f/XXXXX
   - abra o index.html
   - localize: data-form-action="https://formspree.io/f/SEU_ID_AQUI"
   - troque pelo seu endpoint real
3) Suba os arquivos no Cloudflare Pages.
4) Depois substitua os textos de depoimentos pelos reais.
5) Troque os links de Google Maps e Wikiloc pelos links oficiais da rota.

Observação:
Os detalhes das etapas foram deixados em modal e já podem ser refinados com altimetria, pontos de água, apoio e atrativos.
